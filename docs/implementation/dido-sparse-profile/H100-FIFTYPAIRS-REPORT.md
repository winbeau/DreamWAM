候选 SR 比同批 Dense **下降 16 个百分点，超过允许的 5 个百分点**，本轮未达标。
8 对为 Dense 成功而候选失败，0 对相反，42 对均成功。任务分层配对 bootstrap
（10000 次，seed42）给出的差值 95% 区间为 **[−24, −8] 个百分点**；
精确 McNemar 双侧 p=0.0078125。单臂不确定性采用上表 Wilson 区间；不能把
全成功 Dense 的退化 bootstrap [100%,100%] 当作总体 SR 的确定性。

热态模型预测约 **2.031×** 加速；按 episode 等权的均值比为 **2.032×**。
这里统计完整 `predict_action`，热态定义为每条 episode 的 call_index>1 且
prompt-cache 命中。模型加载、IPC、物理模拟、CPU 渲染不计入模型预测计时；
所有调用一栏保留每条 episode 的首次预测。

完整 episode 平均耗时反而 **增加 39.00%**。候选需要更多动作，且 8 个失败
回合均跑满 400 步，环境耗时的增加抵消了模型预测节省。两卡并行的控制器实际
总耗时为 **1920.47 秒，约 32 分钟**，包括模型启动及两臂切换，不含前置准备。
闭环观测与长度可因策略而分化，因此这次 2.031× 是闭环观测上的描述性时延比，
不是额外的同输入离线重放计时。本轮没有另加 GPU 推理测速样本。
